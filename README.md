# 🛒 E-Commerce Analytical Dashboard | Power BI

An interactive **E-Commerce Analytics Dashboard** developed using **Microsoft Power BI** to transform product data into meaningful business insights. The dashboard provides visual analysis of brands, categories, selling prices, MRP, product sizes, and lead-time information through interactive KPIs, charts, tables, and filters.

---

## 📌 Project Overview

The **E-Commerce Analytical Dashboard** is a Business Intelligence project created using Microsoft Power BI. It helps users explore and analyze e-commerce product data through an interactive and visually engaging dashboard.

The dashboard focuses on identifying patterns across **brands, categories, pricing, sizes, and lead time**, making complex product data easier to understand and analyze.

---

## 🎯 Objectives

- Analyze e-commerce product and brand distribution.
- Compare different product categories.
- Analyze selling-price patterns.
- Compare MRP across categories.
- Understand product size distribution.
- Analyze lead-time information.
- Provide interactive and easy-to-understand business insights.

## ✨ Key Features

### 📌 KPI Cards

The dashboard provides key metrics for quick analysis, including:

- Total Brands
- Categories
- Sell Price
- MRP
- Sizes
- Lead Time

### 🏷️ Brand Analysis

Provides a detailed view of brand distribution and allows users to explore individual brands interactively.

### 🗂️ Category Analysis

Visualizes product distribution across different e-commerce categories and enables category-wise comparison.

### 💰 Price Analysis

Analyzes selling prices across categories to identify pricing patterns and differences.

### 🏷️ MRP Analysis

Provides category-wise MRP information through interactive tables and visualizations.

### 📦 Size Analysis

Analyzes the distribution of available product sizes across categories.

### ⏱️ Lead Time Analysis

Provides insights into lead-time information associated with the products.

### 🔍 Interactive Filtering

Users can interact with the dashboard using brand selections, filters, and visual elements to explore the data dynamically.
